A chat column on your own page

The page stays as it is. Chat opens in a narrow column on the right, using openChat from this package.

  1. Sign in with Beagle, then choose This computer or app.beagle.chat, and approve in the window that opens. The header keeps that name and userid above the column. Signing in does not open the column.
  2. Chat, the button at the lower right, opens the column as that signed-in userid. An address opens that friend. This computer is embedded in the column. app.beagle.chat keeps its key in its own tab, so the column shows a link.
  3. With nobody signed in, Chat still opens. It uses a key this browser made for this page. Sign out drops the session only. It does not delete that key, the name, the avatar, or the description. Close hides the column.
